# insta360-edit

A Claude Code skill that edits Insta360 360° footage, phone videos and photos into
professional 9:16 and 16:9 videos with ffmpeg: keyframed reframing of the sphere (pans,
tilts, zooms, follow-a-person), scout frames so Claude can pick directions, background
music with ducking, loudness normalization.

It builds on [ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) (pinned, checksum
verified) for cutting, joining, photos, audio and export, and adds the 360 camera work.

## Install (macOS, Apple Silicon)

```sh
./install.sh
```
